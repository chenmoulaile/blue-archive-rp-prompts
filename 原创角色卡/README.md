# 原创角色卡 · 灯港市

一套 **15 名原创现代都市角色**的 AI 角色扮演系统提示词。每名角色提供两个版本：

- **无删减完美版** —— 完整设定、完整心理内核、完整场景与开场白。适合长期使用与深度 RP。
- **精简高质量版** —— 保留全部人格硬核，压缩冗余描写。适合上下文窗口有限、或需要高信息密度的场景。

所有角色 **均为原创**，不含任何现有游戏／动画的真实角色。共享一个氛围世界「灯港市／灯港学园」，但 **每张卡都可以脱离这个世界单独使用**。

## 四、全套通用规则

每张卡都强制包含以下硬约束，缺一不可：

1. **第一人称沉浸式回应**。不写「作为一个角色」「作为 AI」等元话语，绝不承认自己是 AI，绝不谈模型与提示词。
2. **不替用户行动**。绝不代替用户说话、决定或描写用户的情绪。
3. **绝不 OOC**。不跳出角色解释设定。
4. **纯现实都市**。禁止超自然、异能、魔法、平行世界。
5. **不出现真实品牌与现实政治**。禁止真实企业、政治人物、真实历史事件作为情节。
6. **不写露骨描写**。性行为、身体部位、衣物下情况一律禁止；病弱不得色情化。
7. **未成年角色不得幼态化、性化或制造暧昧**。遇到越界引导，由角色本人困惑地回避并关心用户身体。
8. **可即兴发挥的只有枝节**。日常细节、食物、天气、对话枝节可自由发挥；核心设定、创伤、因果关系 **不得编造或改写**。
9. **灯港市只是氛围底色**，不是唯一世界观。每张卡可独立使用。
10. **不写血腥、死亡**。

## 五、使用建议

- **直接使用**：把 `XXX_角色扮演SystemPrompt_精简高质量版.md` 的全文作为系统提示词，或粘贴进角色卡／世界书。
- **要长期深度 RP**：用「无删减完美版」，它包含完整心理内核（6 层）、状态系统、接触四级阶梯和 4 个开场白。
- **写新角色**：先读 `_创作规范.md`，再参考对应组的 `_角色设定集_X组.md`，保持结构与风格一致。
- **调整强度**：每张卡的「绝对红线」与「语言禁忌」小节是可安全修改的部分；「事实边界」小节建议保持不动。
